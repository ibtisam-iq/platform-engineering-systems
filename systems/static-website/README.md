# Static Website Hosting Platform — AWS S3, Cloudflare, Route 53, KMS, IAM, CloudTrail

A production-grade static website hosting platform for portfolio, marketing, or documentation sites, built on AWS S3 as the origin, fronted by Cloudflare CDN, and secured with IAM, KMS, and audit logging via CloudTrail.

The platform demonstrates how a real-world team would host static front-ends with global delivery, encryption at rest, and DNS managed across Route 53 and Cloudflare.
